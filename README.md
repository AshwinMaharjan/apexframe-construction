# ApexFrame Construction

A modern construction company website built with React and Bootstrap. Browse services, explore completed projects, and get in touch, all wrapped in a clean, responsive layout.

## Features

**Services Showcase** — highlights the core construction and contracting services offered  
**Project Portfolio** — displays completed projects with descriptions and visuals  
**Responsive Design** — works cleanly on mobile, tablet, and desktop  
**Component-Based UI** — built with reusable JSX components for a maintainable codebase  
**Bootstrap Styling** — consistent and polished layout using Bootstrap's grid and utilities  

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React |
| Language | JavaScript (JSX) |
| Styling | Bootstrap |
| Build Tool | Vite |

## Getting Started

### Prerequisites

- Node.js (v18 or above)
- npm or yarn

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/AshwinMaharjan/apexframe-construction.git
cd apexframe-construction

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.
